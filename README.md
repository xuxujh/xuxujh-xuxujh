## 🚀 Portfólio de Engenharia de Dados & IA (End-to-End)

Repositórios avançados de produção desenvolvidos com pipelines de CI/CD rigorosos (*Ruff* e *GitHub Actions*), testes automatizados (*Pytest*) e validação de contratos de dados (*Pydantic v2*).

### 1. 🏗️ [etl-medallion-data-pipeline](https://github.com/xuxujh/etl-medallion-data-pipeline)
* **Arquitetura Medallion** (Bronze, Silver, Gold) orientada a performance com **Polars** e **DuckDB**.
* Validação de contratos de dados estritos via **Pydantic v2**.
* Testes unitários automatizados e pipeline de CI/CD integrado com selo verde (*Success*).

### 2. 🧠 [deep-learning-nlp-inference-api](https://github.com/xuxujh/deep-learning-nlp-inference-api)
* Fine-tuning e inferência de modelos **PyTorch** baseados em Transformers para classificação semântica de textos.
* Servida via **FastAPI** assíncrona com anotações estritas de tipagem (`ClassVar`) e linter **Ruff** configurado.
* Testes de integração de API e Dockerfile otimizado para ambientes de produção.

### 3. 📊 [mlops-tabular-credit-risk](https://github.com/xuxujh/mlops-tabular-credit-risk)
* Pipeline **MLOps** *end-to-end* utilizando **Scikit-learn** (`ColumnTransformer` e `GradientBoosting`).
* Módulo de monitoramento contínuo de **Data Drift** baseado no teste estatístico Kolmogorov-Smirnov (**SciPy**).
* API de predição em tempo real e validação de inferência via **Pydantic v2**.

### 4. ⚡ [big-data-distributed-analytics](https://github.com/xuxujh/big-data-distributed-analytics)
* Processamento analítico em larga escala **OLAP Out-of-Core** utilizando **DuckDB** e **PyArrow**.
* Armazenamento colunar com particionamento otimizado (*Hive-style partitioning*) em **Apache Parquet**.
* Compressão de alta densidade em **ZSTD** e *predicate pushdown* para máxima eficiência de memória RAM.
